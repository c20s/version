# Version

In order to keep track of changes that affects a build artifact we want to use a human readable version scheme.

## ⛓️ Problem

When consumers depend on our software we want them to be able to use the latest version without the risk of their software to break.

## ✨ Solution

We use the SemverScheme to communicate breaking changes, new features and fixes.

🔗 [SemVer](https://semver.org/)
